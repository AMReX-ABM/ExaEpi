# Hospital-capacity data

Acute-care hospital **bed supply per U.S. county** (and optionally per census
tract), for ExaEpi's medical-workers / hospital model. When
`hospital_model.use_HHS_data = true`, ExaEpi reads one of these `.dat`
files and sets each community's staffed-bed supply from the real bed supply of
its county (or tract), instead of the uniform `staffed_beds_per_1000 ×
population` default.

Only acute-care facilities are kept (those that admit infectious-disease
inpatients): `STATUS=OPEN` and `TYPE` in `{GENERAL ACUTE CARE, CRITICAL
ACCESS}`; psychiatric, rehabilitation, children's-only and military facilities
are excluded.

The files are generated by
[`utilities/build_hospital_data.py`](../../utilities/build_hospital_data.py).
Raw source downloads (`.csv`, `.zip`, shapefiles) are git-ignored; only the
processed `.dat` files are committed. Committed examples (HHS, week of
2020-09-27): county files `{CA,BayArea,NM,MA,US}_hospitals_2020.dat` and
tract files `{CA,BayArea,NM,MA,US}_hospitals_tract_2020.dat`.

## Data sources (public)

- **HHS "COVID-19 Reported Patient Impact and Hospital Capacity by Facility"**
  (HealthData.gov, `anag-cw7u`) — facility-level **staffed** and **ICU** beds,
  weekly 2019-2024, year-tied. Reliable Socrata API; the default `--source hhs`.
  <https://healthdata.gov/Hospital/COVID-19-Reported-Patient-Impact-and-Hospital-Capa/anag-cw7u>
- **HIFLD "Hospitals"** — a legacy alternative (`--source hifld`). HHS already
  provides hospital locations (its `geocoded_hospital_address`), so HIFLD is not
  needed for tract placement. **HIFLD Open is being deprecated** (layers move to
  the account-gated HIFLD Secure), so this path expects a locally supplied CSV
  (`--hifld-csv`).

## Quickstart

Install dependencies (county level needs only `pandas`; tract level adds
`geopandas`/`scipy`):

```
pip install -r ../../utilities/requirements-hospital-data.txt
```

Run from this directory (`data/HospitalData/`). Each command below produces the
file ExaEpi consumes for that region. Pick a year and the matching HHS week
(Sunday-dated, e.g. `2020-09-27`); re-run with a new `--year`/week to update.

```
SCRIPT=../../utilities/build_hospital_data.py

# California (matches CA.dat / CA_scaled.dat)
$SCRIPT --state CA --year 2020 --source hhs --download --hhs-week 2020-09-27 \
        --out CA_hospitals_2020.dat

# San Francisco Bay Area (matches BayArea.dat) -- the 9 Bay Area counties
$SCRIPT --state CA --year 2020 --source hhs --download --hhs-week 2020-09-27 \
        --counties 06001 06013 06041 06055 06075 06081 06085 06095 06097 \
        --out BayArea_hospitals_2020.dat

# New Mexico (matches NM_TX_2010.dat)
$SCRIPT --state NM --year 2020 --source hhs --download --hhs-week 2020-09-27 \
        --out NM_hospitals_2020.dat

# Massachusetts (matches MA.dat)
$SCRIPT --state MA --year 2020 --source hhs --download --hhs-week 2020-09-27 \
        --out MA_hospitals_2020.dat

# Whole United States (matches US.dat) -- omits the state filter
$SCRIPT --state US --year 2020 --source hhs --download --hhs-week 2020-09-27 \
        --out US_hospitals_2020.dat
```

Then point ExaEpi at the file:

```
agent.model_medical_workers = true
hospital_model.use_HHS_data = true
hospital_model.hospital_data_file = data/HospitalData/CA_hospitals_2020.dat
```

### Tract-level (placement + patient routing)

Tract level places hospitals where they exist and routes each tract's patients
(and medical staff) to the nearest hospital tract. It uses the same HHS source
(its geocoded hospital points) plus a Census tract shapefile — needs
`geopandas`/`scipy`. A CA TIGER shapefile ships in `../CA_2020_Census_Tracts/`;
for other states use the national cartographic-boundary tract file (one file,
all states), `cb_2020_us_tract_500k` from
<https://www2.census.gov/geo/tiger/GENZ2020/shp/cb_2020_us_tract_500k.zip>.

```
# California, using the bundled CA TIGER shapefile
SHAPE_RESTORE_SHX=YES $SCRIPT --state CA --year 2020 --source hhs --download \
        --hhs-week 2020-09-27 --level tract \
        --tract-shapefile ../CA_2020_Census_Tracts/tl_2020_06_tract.shp \
        --out CA_hospitals_tract_2020.dat

# NM / MA / US, using the national tract shapefile (--state US for the country)
$SCRIPT --state US --year 2020 --source hhs --download --hhs-week 2020-09-27 \
        --level tract --tract-shapefile cb_2020_us_tract_500k.shp \
        --out US_hospitals_tract_2020.dat

# the Bay Area must use the 2000-vintage tract shapefile that matches BayArea.dat
SHAPE_RESTORE_SHX=YES $SCRIPT --state CA --year 2020 --source hhs --download \
        --hhs-week 2020-09-27 --level tract \
        --counties 06001 06013 06041 06055 06075 06081 06085 06095 06097 \
        --tract-shapefile ../San_Francisco_Bay_Region_2000_Census_Tracts/region_2000_censustract.shp \
        --out BayArea_hospitals_tract_2020.dat
```

(`SHAPE_RESTORE_SHX=YES` lets GDAL rebuild the `.shx` index if a shapefile ships
without one.)

**Tract vintage must match the demographic file.** `BayArea.dat` is built on
2000-vintage census tracts (1405 tracts; e.g. San Francisco has 176, not the 197
of 2010). The hospital points must be spatial-joined to the *same* vintage, so
the Bay Area command uses `San_Francisco_Bay_Region_2000_Census_Tracts/`, not the
2020 CA TIGER file. Joining to 2020 tracts silently drops the beds of every
hospital that sits in a post-2000 tract split: 20 of the 60 Bay Area facilities,
about a third of the beds, land in tracts `BayArea.dat` does not have and are
never placed. (The CA, NM, MA and US examples above use 2020 TIGER because their
demographic files are 2010/2020-vintage; only the Bay Area run is 2000-vintage.)

## File format

`#`-comment provenance lines, then a record count, then one row per geography:

```
# provenance ...
<N>
FIPS  beds  icu_beds  n_hospitals                              (county level)
FIPS  TRACT  beds  icu_beds  n_hospitals  hosp_FIPS  hosp_TRACT (tract level)
```

- `FIPS` — integer county FIPS (e.g. `6037` = Los Angeles County), matching the
  integer FIPS in the demographic `.dat` files. `TRACT` is `int(TRACTCE)`
  (e.g. `400` for tract `000400`).
- `beds` — staffed acute-care beds (the supply at full workforce strength).
- `icu_beds` — staffed adult ICU beds (`0` if HHS data was not used).
- `hosp_FIPS`/`hosp_TRACT` (tract level) — the hospital tract this tract's
  patients are routed to (itself if it has a hospital, else the nearest one).

## Scope

County-level data drives a per-county bed-density override (every community's
supply is its county's real supply apportioned by population). Tract-level data
additionally places hospitals at real tracts and routes patients to the nearest
hospital tract, reusing ExaEpi's home↔work movement machinery.
